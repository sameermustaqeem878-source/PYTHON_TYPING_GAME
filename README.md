# Python Typing Game

Words related to Python fall from the top. Type each word and press Enter before it touches the ground.

## Run
Open `index.html` in any browser. No install or server needed.

## Files
- index.html - page structure
- style.css  - night-city theme, glowing word cards, HUD
- game.js    - game logic (words, difficulty, speed, lives, score)

## Difficulty
- Easy: basic keywords
- Medium: common libraries and OOP names
- Hard: advanced concepts and dunder methods

Speed rises and words spawn faster as time passes. Esc opens Settings / pauses.
To add words, edit the WORDS object at the top of game.js.

## Run with npm (optional)
Needs Node.js installed (nodejs.org).

    npm start

This serves the game at http://localhost:3000 and opens your browser. Stop with Ctrl + C.
